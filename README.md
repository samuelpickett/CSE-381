# Snake

A game of snake with customizable snake/apple and adjustable board as well as an autoplay feature

## Instructions for Build and Use

Steps to build and/or run the software:

1. Clone repository from GitHub
2. Run file on computer


Instructions for using the software:

1. Use up/down or W/D and enter to navigate menu. Use left/right or A/D in option menu to adjust color and speed
2. Enter a number between 16-200 to create a map.
3. Use ESC to go back, hit enter while selecting play to start the game. 
4. Use arrow keys or WASD to control the snake. 
5. Use ESC to return to the menu or hit R on death to restart the game. 
6. Hit P to toggle the autoplay feature. 

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* VS Code
* Python 3.11
* Arcade, Random, HeapQ, itertools, math, collections, and __future__ libraries
